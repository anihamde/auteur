# @auteur/component-library

The fifteen design-system primitives.

Layer: `ui`. It may import packages in its own layer or below, never above.

## Dependencies

`@auteur/copy`, `@auteur/core`, `@auteur/formatting`, `@auteur/icons`, `@auteur/tokens`, `@base-ui-components/react`, `@pandacss/dev`, `react`, `react-dom`
