# @auteur/icons

The closed-set Lucide binding, and the only way to draw an icon.

Layer: `foundation`. It may import packages in its own layer or below, never above.

## Dependencies

`@auteur/tokens`

## Public surface

See `api-surface.md`, which CI regenerates and compares on every pull request.

## Testing

```sh
bun run turbo test --filter @auteur/icons
```
